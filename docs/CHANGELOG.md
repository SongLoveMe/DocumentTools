# Changelog

## 2.0.0 - 2026-08-20

- Added PDF page operations: split, extract, delete, reorder, page numbering and rotation.
- Added PDF conversions to Excel, PNG and JPG.
- Introduced the categorized V2 PDF workbench and contextual UI controls.
- Consolidated UI implementation under `src/documenttools/ui/`.
- Added structured output logs and output-directory controls.
- Unified the project version independently from third-party dependency versions.
